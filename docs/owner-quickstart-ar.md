# دليل المالك: تثبيت المدرسة وتجربتها (NG Academy)

هذا الدليل يأخذك من «لا شيء» إلى «أمشي داخل مدرستي» على جهازك الشخصي.
الفرع الحالي: `arena/01a096db-workadventure` — كل العمل موجود عليه ومرفوع.

## المتطلبات

- Docker + Docker Compose (لتشغيل حزمة العالم: play/pusher/map-storage/livekit/postgres/redis).
- Node.js 22+ وnpm (لأدوات التطوير وبوابة الكبار).
- صلاحية تعديل ملف hosts على جهازك.

## 1) التنزيل والتجهيز

```bash
git clone https://github.com/Abdo12-del/workadventure.git
cd workadventure
git checkout arena/01a096db-workadventure
./bootstrap.sh
```

`bootstrap.sh` ينشئ `.env` من `.env.template` (خريطة المدرسة صارت الغرفة الافتراضية
جاهزًا)، ويثبّت الحزم، ويولّد ملفات protobuf اللازمة للبناء.

## 2) تشغيل العالم بدون docker (الطريقة الأسرع)

بدل حزمة docker كاملة يمكنك تشغيل العالم بأمر واحد (node فقط):

```bash
npm run world:native
```

يشغّل الأمر أربع عمليات (خادم خرائط ساكن، map-storage، back، play) ويفتح العالم على
`http://localhost:3104` — اختر اسمًا وأفاتارًا كرتونيًا وامشِ داخل المدرسة.
لا يحتاج Redis ولا Postgres ولا LiveKit (فقاعات الصوت تُفعَّل لاحقًا عند ضبط LiveKit).

## 2ب) أو تشغيل حزمة docker الكاملة

```bash
docker compose up -d
```

أضف هذا السطر إلى ملف hosts:
- لينكس/ماك: `/etc/hosts`
- ويندوز: `C:\Windows\System32\drivers\etc\hosts` (محرر بصلاحية مدير)

```
127.0.0.1 play.workadventure.localhost pusher.workadventure.localhost map-storage.workadventure.localhost ng-portal.workadventure.localhost
```

## 3) ادخل المدرسة (العالم الماشي)

افتح في المتصفح:

```
http://play.workadventure.localhost
```

- شاشة بسيطة: اختر اسمًا وأفاتارًا كرتونيًا ← دخول.
- ستقف في **المدخل والاستقبال**: فقاعة ترحيب من «جينو» (مرشد ودود غير مزعج).
- امشِ بالأسهم أو WASD. الأبواب العلوية = الفصول السبعة (عربي، إنجليزي، حساب، علوم،
  شطرنج، قراءة، تواصل). الجانبية = المكتبة والمختبر والمسرح وقاعتا الإبداع والإنجازات.
- جرّب ركن المعداد: ادخل فصل الحساب وقف على السجادة الصفراء ← يفتح المعداد التفاعلي وحده.
- القرب يفتح الصوت: شخصان قريبان داخل فصل = حصة صوتية مشرفة تُفتح وتُغلق تلقائيًا.
  (لا دردشة نصية عامة، ولا رسائل خاصة، ولا دعوات خارجية: سلامة الأطفال مفروضة.)

## 4) بوابة الكبار ولوحة الإدارة داخل العالم

`npm run world:native` يشغّل بوابة الكبار أيضًا على
`http://localhost:3100/portal/` (أزرار الدخول الفوري تظهر في بيئة التطوير فقط).

**قرار المالك: لا لوحة إدارة منفصلة.** بعد دخول المالك/الإدارة من البوابة تظهر صفحة
«الإدارة تعيش داخل العالم» وزرها **«ادخل العالم بصلاحيات الإدارة»** يفتح العالم
حملًا لجلستك (`#ngToken=…`). داخل العالم: قف على منطقة **مكتب الإدارة** في قاعة
المدخل (entrance) لتفتح اللوحات الخمس داخل الخريطة: نظرة عامة، المستخدمون،
الفصول والدورات، الأنشطة، مناطق العالم. الخروج من المنطقة يغلق اللوحات، وغير
الإدارة يسمع اعتذار جينو اللطيف بدلها.

## 5) رحلة الطفل المقصودة (قيد الوصل)

طرف الـAPI جاهز ومختبر: `POST /ng/children/:id/session` يصدر جلسة طفل موقّعة
(ولي الأمر فقط). زر «افتح العالم لياسمين» داخل بوابة ولي الأمر واستقبال الرمز في
جهة العالم سيصلان في دفقة قادمة؛ حتى ذلك الحين الدخول التجريبي للعالم يتم من شاشة
الاسم/الأفاتار أعلاه.

## استكشاف الأخطاء

- **الخريطة لا تُحمل / شاشة فارغة**: تأكد من سطر hosts ومن أن `docker compose ps`
  يظهر كل الخدمات running، وأن `.env` فيه `START_ROOM_URL=.../ng-academy/entrance.wam`.
- **خطأ protobuf عند البناء**: نفّذ `npm run bootstrap -- --proto-only`.
- **الصوت لا يعمل**: أول دخول يحتاج سماح المتصفح بالميكروفون؛ داخل الفصول فقط.
- **بيانات العرض تُصفّر**: خادم `dev:memory` يخزن في الذاكرة؛ كل إعادة تشغيل = بذور جديدة.

- `docs/ng-school-overview.png` — صورة مجمعة محدثة للغرف الـ13.
- `play/` — محرك العالم (واجهة WorkAdventure بهوية NG وقواعد السلامة).
- `ng-academy-api/` — API الكبار (جلسات، أطفال، حصص، مناطق العالم) + خادم العرض.
- `ng-academy-portal/` — بوابة الكبار (دخول سحري، لوحات تقليدية بالعربية).
- `docs/agent/dev-setup.md` — إعداد التطوير الكامل بالإنجليزية لفريق العمل.
