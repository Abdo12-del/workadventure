# NG Academy — بوابة ولي الأمر ولوحة الإدارة

`ng-academy-portal` هو تطبيق Svelte + Vite صغير (≈24KB مضغوط) مخصص **للكبار فقط**:
ولي الأمر، المعلم، الإدارة والمالك. الطفل لا يدخل هذه البوابة أبدًا — عالم المدرسة
هو صفحته الرئيسية (البنود 12، 13، 14، 19).

## الشاشات

| المسار      | لمن            | المحتوى                                                                                            |
| ----------- | -------------- | -------------------------------------------------------------------------------------------------- |
| `#/login`   | الجميع         | دخول بالرابط السحري (يصل لبريد ولي الأمر/المعلم/الإدارة — الأطفال بلا بريد ولا كلمات مرور)         |
| `#/parent`  | ولي الأمر      | أطفاله فقط: لمحة (نقاط/شارات)، الحضور، الشارات، ملاحظات المعلمين، الفصول والمواعيد                 |
| `#/teacher` | المعلم         | فصوله وقوائم طلابه: تسجيل حضور، منح شارات، إكمال أنشطة، كتابة ملاحظات لولي الأمر                   |
| `#/admin`   | الإدارة/المالك | نظرة عامة (عدّادات)، المستخدمون (إنشاء + ربط طفل بولي أمر)، الفصول والدورات، الأنشطة، مناطق العالم |

التصميم **تقليدي هادئ** (جداول/بطاقات/فلاتر) بأزرق ناضج `#0369a1` — مختلف تمامًا عن
ألوان عالم الطفل المرحة، وRTL بالكامل.

## التطوير

```bash
# طرف 1: الـAPI بذاكرة مزروعة (بلا Postgres) — روابط الدخول تُطبع في الطرفية
npm run dev:memory --workspace ng-academy-api

# طرف 2: البوابة على http://localhost:3200/portal/ (تعمل proxy إلى :3100)
npm run dev --workspace ng-academy-portal
```

جرّب: `parent@ng.example` (ولي أمر)، `hasiba@ng.example` (معلمة)،
`admin@ng.example` (إدارة). الرابط السحري يُطبع في سجل الـAPI — الصق الرمز في
خانة «الصق الرمز» أو افتح الرابط كاملًا (`#/login?token=…` يُستهلك تلقائيًا).

متغيرات البيئة: `NG_API_PROXY` (هدف الـproxy، افتراضيًا `http://localhost:3100`)
و`PORTAL_PORT` (افتراضيًا 3200).

## الإنتاج

```bash
npm run build --workspace ng-academy-portal
PORTAL_DIST=/path/to/ng-academy-portal/dist  # في بيئة ng-academy-api
```

فيصبح الموقع على نفس نطاق الـAPI:‏ `http://ng-api…/portal/` (بلا CORS إضافي)،
أو عبر خدمة `ng-academy-portal` في docker-compose على
`http://ng-portal.workadventure.localhost/portal/`.

## الاختبارات

```bash
npm run test --workspace ng-academy-portal       # 10 اختبارات (api/auth/router)
npm run typecheck --workspace ng-academy-portal  # tsc + svelte-check
```

## قواعد أمان مطبَّقة هنا (تذكير)

- الجلسة JWT في `localStorage` تحت مفتاح `ng-portal-token` **المنفصل** عن جلسة
  الطفل في العالم (`ng-token`)؛ انتهاء الجلسة يعيد إلى شاشة الدخول بصمت.
- كل الحراسات (طفل/ولي أمر/معلم/إدارة) تُفرض **في الخادم**؛ الواجهة تعرض فقط.
- لا بيانات شخصية للأطفال: اسم أول، بريد ولي الأمر فقط، ولا صور حقيقية.
